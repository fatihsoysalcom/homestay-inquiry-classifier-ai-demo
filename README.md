# Homestay Inquiry Classifier AI Demo

This example demonstrates a basic open-source AI concept for a homestay business like Eden Homes. It classifies customer inquiries into categories (e.g., Reservation, Amenities) using keyword matching and suggests automated responses. This helps small businesses automate customer service and improve operational efficiency with limited resources.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`. Type your inquiries and press Enter. Type 'exit' to quit.
